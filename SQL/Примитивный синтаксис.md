PRIMARY KEY (первичный ключ)
Это главный идентификатор строки, он автоматически делает поле уникальным и запрещает в нем пустые значения

UNIQUE (Уникальность)
Запрещает дубликаты. В отличие от Primary key, можно создать сколько угодно раз ограничений

FOREIGN KEY (Внешний ключ)
Связывает таблицы между собой. он гарантирует, что вы не сможете добавить запись в дочернюю таблицу, если связанной записи нет в родительском

```SQL
ON DELETE CASCADE - Если удалить строку в главной таблице связаные строки в таблице удалятся автоматически
ON DELETE SET NULL - Если удалить главную строку в текущей таблице после связи очистится
```

## 1. Общие сведения и назначение
Проект автоматизирует персональный коучинг стрельбы в FPS-шутерах. Система анализирует статистику матчей, выявляет слабые механики, генерирует персонализированные тренировочные сеты (Aim Lab / KovaaK's) и предоставляет голосовой/текстовый AI-коучинг внутри Telegram Mini App. Монетизация через тарифную сетку (Bronze/Silver/Elite).

## 2. Технологический стек (2026)

| Уровень | Технология | Обоснование |
|:---|:---|:---|
| **Frontend (TMA)** | React 19 + TypeScript + Vite + `@twa-dev/sdk` + Tailwind CSS + Recharts | Официальный SDK, типобезопасность, OLED-тема, Spider Chart, bundle <1MB |

| **STT / TTS** | Deepgram (streaming) + ElevenLabs (pay-as-you-go) | Низкая латентность STT, эмоциональный TTS, кэширование аудио в Storage |

| **CI/CD & Hosting** | GitHub Actions → Cloudflare Pages (TMA) + Supabase (backend) | Zero-config, CDN, автоматические деплои по веткам |
| **Мониторинг** | PostHog (product) + Sentry (errors) + OpenRouter/Gemini dashboards | Трекинг конверсий, стоимость AI, latency, падения |

## 3. Функциональные требования

### 3.1. AI Coach Core & Function Calling
- **Роль:** Эксперт по FPS-механикам (Flick, Track, Micro-adjust, Switch, Spray).
- **Вход:** `sens`, `dpi`, `game`, `tier`, `recent_matches`, `weak_mechanics`.
- **Выход:** JSON-структура с рекомендациями, Share Code, текстовый/голосовой ответ.
- **Инструменты (Tools):**
  - `get_tracker_stats(player_id, platform)`
  - `analyze_match_performance(match_data)`
  - `generate_playlist_code(aim_type, duration)`
- **Ограничения:** `temperature ≤ 0.2`, контекст ≤ 8K токенов, cache_control для системного промпта.

### 3.2. Голосовой модуль
- **STT:** Deepgram streaming (`model: smartest`, `language: auto`, `smart_format: true`).
- **TTS:** ElevenLabs (`model: eleven_multilingual_v2`, `stability: 0.7`, `similarity_boost: 0.8`).
- **Кэширование:** Аудио сохраняется в Supabase Storage с TTL 30 дней. Повторный запрос → отдача кэша.

### 3.3. Тарифная сетка & Platega
| Функционал | Bronze (Free) | Silver (Pro) | Elite (Ultimate) |
|:---|:---|:---|:---|
| Аналитика | Текст/голос пользователя | Подробный разбор | Авто (FACEIT/Tracker API) |
| Интеграции | — | — | FACEIT, Tracker.gg |
| Лимиты AI | 10 текстовых/день | Безлимит текст + 30 голосовых | Безлимит (текст + голос) |
| Плейлисты | 1/неделя (текст) | 3/неделя (Share Code) | Авто после каждого матча |
| Статистика | Ручной | Ручной + Streaks | Авто в БД |
| Уведомления | — | Напоминания | За 20 мин до прайма + Anti-Tilt |

- **Синхронизация:** Platega webhook → Edge Function → проверка подписи → обновление `profiles.pro_tier` → `subscription.expires_at`.
- **Проверка доступа:** Серверная валидация в каждом Edge Function и TMA-экране.

### 3.4. UI/UX & TMA Native
- **Тема:** OLED Black `#0F1015`, CS2 `#FF5500`, Valorant `#FF4655`, AI `#8A2BE2`.
- **Экраны:** Dashboard (Spider Chart, Streak, MainButton), Playlist Hub, Integrations & Stats.
- **Нативные API:** `Telegram.WebApp.HapticFeedback`, `MainButton`, `expand()`, `ThemeParams`.
- **Адаптивность:** iOS/Android/Desktop. Safe-area, динамические шрифты, отключение тяжёлых анимаций на слабых устройствах.

### 3.5. Уведомления & Anti-Tilt
- **Push:** Telegram Bot API (`sendNotification` + `chat_id` из профиля).
- **Anti-Tilt:** Активация при `headshot_first% < 30%` за 3 матча подряд → мотивирующий голосовой ответ + рекомендация перерыва.
- **Pricing Reminder:** Напоминание за 20 мин до истечения подписки.

## 6. Структура данных (Supabase)

|Таблица|Назначение|Ключевые поля|
|---|---|---|
|`profiles`|Пользователи|`id` (auth), `tg_id`, `pro_tier`, `expires_at`, `created_at`|
|`tiers`|Прайс/лимиты|`name`, `price_id_platega`, `text_limit`, `voice_limit`, `playlist_limit`|
|`match_logs`|История матчей|`user_id`, `platform`, `game`, `shot_accuracy`, `hs_first%`, `kda`, `raw_data` (JSONB)|
|`coach_sessions`|Диалоги AI|`user_id`, `input_type`, `output`, `tokens_used`, `cost`, `created_at`|
|`aim_playlists`|База сценариев|`game`, `aim_type`, `duration`, `share_code`, `tags`, `created_at`|
|`user_stats`|Агрегация|`user_id`, `flick_score`, `track_score`, `micro_score`, `switch_score`, `spray_score`, `streak`, `updated_at`|

- **RLS:** `auth.uid() = user_id` для всех таблиц. Ручной доступ только через админ-роль.
- **Индексы:** `match_logs(user_id, created_at DESC)`, `coach_sessions(user_id, created_at)`, `user_stats(user_id UNIQUE)`.
- **Векторы:** `pgvector` для семантического поиска по сценариям/механикам (опционально, при >5k MAU).

# Техническое задание (ТЗ): AI-тренер по аиму «AIM Рутина» (Telegram Mini App)

## 1. Общие сведения и назначение системы
**Наименование проекта:** AIM Рутина  
**Формат:** Telegram Mini App (TMA) + AI Agent Backend  
**Целевая аудитория (ICP):** Игроки 16+ (CS2, Valorant), стремящиеся повысить ранг/ELO, ищущие быстрый разгрузочный/тренировочный сет перед каткой и ведущие трекинг своего прогресса.  
**Основная цель:** Автоматизировать персональный коучинг стрельбы, превращая сухую статистику матчей в точечные тренировочный плейлисты (Aim Lab / KovaaK's) без затрат на живых тренеров.

---

## 2. Архитектура AI-агента и логика обработки данных

### 2.1. Контекстный промпт и системная роль (AI Coach Core)
AI-агент выступает в роли экспертного тренера по механикам стрельбы в FPS-шутерах.
*   **Входные параметры пользователя:** Sens (DPI + внутриигровая чувствительность), целевая игра (CS2 / Valorant), текущий ранг/ELO, выявленные слабые стороны (*Flick, Track, Micro-adjust, Switch, Spray*).
*   **Голосовой модуль (Voice-to-Text / Text-to-Voice):**
    *   Интеграция STT (Whisper / Deepgram) для распознавания голосовых сообщений пользователя с геймерским сленгом.
    *   Генерация голосовых ответов через TTS (ElevenLabs) с акцентом на лаконичный и мотивирующий тон.

### 2.2. Набор инструментов ИИ (Function Calling / Tools)
1.  `get_tracker_stats(player_id, platform)` — получение логов последних матчей с FACEIT / Tracker.gg API.
2.  `analyze_match_performance(match_data)` — вычисление аномалий (низкий % Headshot первым патроном, частые промахи при микро-фликах).
3.  `generate_playlist_code(aim_type, duration)` — подбор и выдача генеративного Share Code для Aim Lab / KovaaK's из размеченной базы данных сценариев.

## 4. Требования к интерфейсу и UI/UX (Telegram Mini App)

### 4.1. Цветовая палитра и стилистика (Dark Gaming UI)
*   **Основной фон:** OLED Black (`#0F1015`).
*   **Акцент CS2 / FACEIT:** Ярко-оранжевый (`#FF5500`).
*   **Акцент Valorant:** Неоново-красный (`#FF4655`).
*   **Акцент AI-системы:** Ультрафиолетовый / Фиолетовый (`#8A2BE2`).

### 4.2. Экраны и ключевые виджеты
1.  **Главный экран (Dashboard):**
    *   Радарная диаграмма (**Spider Chart**) на 5 навыков: *Flick, Track, Micro-adjust, Switch, Spray*.
    *   Текущий ежедневный стрик тренировок (Daily Streak counter).
    *   Быстрая кнопка запуска AI-разбора через системную `MainButton` Telegram.
2.  **Экран Тренировки (Playlist Hub):**
    *   Карточка с текущим рекомендованным плейлистом.
    *   Кнопка 1-Tap Copy для копирования `Share Code` в буфер обмена.
3.  **Экран Интеграций и Статистики:**
    *   Форма привязки аккаунтов FACEIT / Steam / Riot ID.
    *   График динамики ELO/K/D в соотношении с пройденными тренировками.

### 4.3. Нативные возможности Telegram API
*   **Haptic Feedback:** Использование вибрации разных типов (`Light`, `Medium`, `Heavy`, `Success`, `Error`) при взаимодействии с элементами интерфейса и копировании кодов.
*   **Кроссплатформенность:** Адаптация под iOS, Android и Telegram Desktop (режим второго монитора).
*   **Нативные элементы:** Использование `MainButton` в нижней части экрана для совершения целевых действий.

## 5. Сценарий работы пользователя (User Flow — Elite Tier)

1.  Пользователь завершает матч на FACEIT / Valorant.
2.  Бот в фоновом режиме через Webhook получат данные с API трекера.
3.  AI-агент проводит экспресс-анализ: фиксирует падение эффективности первого патрона.
4.  Пользователю приходит Push-уведомление в Telegram с приглашением в Mini App.
5.  В Mini App открывается окно с аудио-коучингом от ИИ и кнопкой скопировать готовый 8-минутный сет для Aim Lab.
6.  Статистика тренировки автоматически записывается в профиль пользователя, обновляя Spider Chart.
